# HireMate — landing page mock-up

A single-page concept landing page for the HireMate course project. Everything is in `index.html` (no build step).

## Publish on GitHub Pages

1. Create a new **public** repository on GitHub, e.g. `hiremate`.
2. Click **Add file → Upload files**, upload `index.html` (and this README), then **Commit changes**.
3. Go to **Settings → Pages**. Under *Build and deployment*, set **Source: Deploy from a branch**, **Branch: `main`**, folder **`/ (root)`**, and click **Save**.
4. Wait 1–2 minutes, refresh the Pages settings, and your link appears:
   `https://<your-username>.github.io/hiremate/`

Tip: name the repository `<your-username>.github.io` instead and the page is served at `https://<your-username>.github.io/`.

## Notes

- The waitlist form is demo-only: it shows a thank-you message and does not send or store emails.
- Testimonials are marked "Placeholder" and a banner states this is a concept mock-up. Keep those labels unless you replace them with real pilot feedback.
